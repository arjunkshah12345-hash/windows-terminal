A real Windows PC for your agent. Inside your terminal.

Genuine Windows 11 in a QEMU virtual machine, drawn right in your terminal. You can click around in it. Your agent drives the same machine over MCP, and your own mouse and keyboard stay yours.

Four commands from nothing to a PC your agent can use

Fetch it

windows-terminal fetch downloads genuine Windows 11 from Microsoft's own CDN, checks it against the SHA-1 in Microsoft's catalog, and builds a bootable ISO. No third-party mirrors.

Boot it

init creates a named VM with its own disk, UEFI and optional TPM 2.0. up --view boots it with Apple silicon (HVF) or KVM acceleration and draws the screen inline: Kitty graphics, iTerm2 images, or true-colour blocks anywhere else.

Click it

Your keyboard and mouse go to the guest: typing, clicks, dragging, scrolling. Ctrl+] detaches and the VM keeps running.

Hand it over

windows-terminal mcp gives any MCP-capable agent nine computer-use tools on the same machine: screenshot, click, type, key, scroll and more. It never moves your host pointer, reads your clipboard or touches your files.

Get started on a Mac or Linux box

# QEMU, a TPM emulator, and the tools fetch uses to build the ISO
$ brew install qemu swtpm wimlib xorriso
$ pipx install git+https://github.com/arjunkshah12345-hash/windows-terminal

$ windows-terminal fetch                         # genuine Windows 11 from Microsoft, ~4.5 GB
$ windows-terminal init --iso win11-*.iso --tpm --unattended
$ windows-terminal up --view                     # Ctrl+] detaches, the VM keeps running
$ windows-terminal mcp                           # hand the same VM to your agent

Debian/Ubuntu: sudo apt install qemu-system-x86 qemu-utils ovmf swtpm wimtools xorriso. A full install needs about 20 GB free. Want a quick look first? fetch --setup-only downloads about 0.56 GB and boots real Windows PE and Setup. Windows is installed unactivated with Microsoft's generic edition key.

What's real, and what isn't verified yet

Shown working

  • Genuine Windows 11 ARM64, fetched and booted to Setup with no keypress
  • Keyboard, mouse, command prompt and Notepad, from you and from an agent over MCP
  • Persistent named VMs, TPM 2.0, offline checkpoints
  • Live tests on ARM and x86 QEMU in CI

Not verified yet

  • A full unattended install all the way to the desktop
  • Networking inside installed Windows on Arm
